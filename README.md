# FacilityFlow – Premium Property & Facility Management Website

A modern, premium, and fully responsive corporate website for a Property & Facility Management company. This project was developed as a frontend hiring assignment using Next.js 15, React, Tailwind CSS, Framer Motion, and modern UI/UX principles.

---

## 🌐 Live Demo

**Live URL:** [https://facilityflow-dev.netlify.app/]

**GitHub Repository:** [https://github.com/sucharita4867/FacilityFlow]

---

## 📖 Overview

FacilityFlow is a premium corporate marketing website designed for a Property & Facility Management company. The website focuses on delivering a modern user experience with elegant layouts, smooth animations, responsive design, and enterprise-level UI.

The design is inspired by modern corporate websites such as Apple, Stripe, Framer, and Vercel while maintaining a unique visual identity.

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Go to the project directory

```bash
cd facilityflow
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

## 📦 Build

```bash
npm run build
```

Start production server

```bash
npm start
```
